## 发现并修复

1. 浏览器用 127.0.0.1，Next 内部使用 localhost，最初同源比较误拒绝正常请求。改为对照实际 Host，并新增回归测试。
2. 本机文件监听数量限制。开发入口改用 Webpack 轮询；说明不要同时构建和启动开发服务。
3. 生成失败后的进度文案残留。失败时清空旧进度，保留明确错误提示。
4. 从页面底部发起新一轮后阅读位置不直观。切换页码/故事时滚动到顶部。
